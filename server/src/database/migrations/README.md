# Database Migrations

This directory will hold version-controlled SQL migration files (e.g. `001_create_hotels_tables.sql`, `002_create_rooms_and_inventory.sql`, `003_create_bookings_and_outbox.sql`).

> **Note**: As specified in the architectural blueprint, the final database schema is subject to evaluator confirmation (PostgreSQL vs. MySQL baseline). Schema migration scripts will be placed here once the schema design is officially approved.
